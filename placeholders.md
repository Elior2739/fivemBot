# Server Data

Automaticlly getting from the server info, If the server is offline and used it will result in `No Data`

| Placeholder         | Description         |
| :----------- | :--------------: |
| %serverOnline% | true or false |
| %serverOnline_S% | Yes or No |
| %currentPlayers% | The amount of current players as number |
| %serverOnline_S% | The amount of current players as string, Example: No Players, 1 Player, x Players |
| %maxPlayers% | The amount of max players as number |
| %maxPlayers_S% | The amount of max players as string, Example: No one is allowed to join, 1 Player Allowed, x Max|
| %upvotePower% | Up Vote power as number |
| %upvotePower_S% | Up Vote power as string, Example: No power, 1 Power, x Power |
| %burstPower% | burst power as number |
| %burstPower_S% | Up Vote power as string, Example: No power, 1 Power, x Power |
| %ownerId% | Server's owner cfx account id (Working by the owner of the license key) |
| %ownerName% | Owner's cfx account profile name |
| %ownerProfile% | Link to the owner's cfx account |
| %ownerAvatar% | Owner's cfx account avatar |
